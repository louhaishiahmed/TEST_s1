# VoiceUp Demo

VoiceUp Demo is a prototype demo site for an anonymous feedback platform designed for universities and educational institutions. It enables students and employees to submit concerns and report problems without fear of identification, ensuring their voice reaches leadership directly.

## How to run locally

1. Install dependencies:
   ```bash
   npm install
   ```

2. Start the development server:
   ```bash
   npm run dev
   ```

3. Open [http://localhost:3000](http://localhost:3000) in your browser

## Note

This is a demo prototype with no backend infrastructure or persistent data storage. All submissions are simulated and not saved.
